# BLP2PNG

This is a python script for converting .blp files to .png files and vice-versa.


                                                  
##    Usage Examples:                                                   
             
  Convert BLP to PNG
  
  `python3 BLPNG.py image.blp`           
  
  Convert PNG to BLP
  
  `python3 BLPNG.py image.png`
